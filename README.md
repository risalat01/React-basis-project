# Tic-Tac-Toe (React)

My first React project — a simple starter build, nothing production-grade.
Made this mainly to get comfortable with core React concepts before moving
on to bigger things.

## What I practiced
- useState and derived state (instead of tracking redundant state)
- Component composition & prop drilling
- Controlled inputs (editable player names)
- Conditional rendering
- Basic game logic (win/draw detection)
